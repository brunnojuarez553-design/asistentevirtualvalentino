    AUSTRAL WEB STUDIO / APP REVIEW

    REVISIÓN DE META.

    Pruebas manuales con activos de prueba. La atención automática permanece desactivada.

    Ingresá con un administrador autorizado para revisar la configuración.

    01 / CONEXIÓN

    Cuenta de prueba

    Las credenciales y el destinatario se configuran exclusivamente en el servidor. Este panel nunca solicita tokens.

      Destinatario autorizado: Sin configurar

      Sin comprobar. Configuración completa no equivale a permisos aprobados.

      02 / MENSAJERÍA DE PRUEBA

      Enviar mensaje de prueba

      Elegí una plantilla de texto aprobada y sin variables. El envío se limita al destinatario configurado; no activa el asistente.

      La aceptación de la API no prueba la entrega. Comprobá la recepción en WhatsApp.

      03 / GESTIÓN DE PLANTILLAS

      Crear plantilla en Meta

      Se envía una solicitud real a Meta en la WABA de prueba. La categoría solicitada es Utilidad; Meta decide su clasificación y aprobación.

      Ninguna plantilla se crea al completar este formulario hasta presionar el botón.

      04 / EVIDENCIA PARA REVISIÓN

      Preparar los dos videos

      1. Mensajería: mostrar acceso al panel, plantilla seleccionada, envío aceptado y recepción del mismo mensaje en WhatsApp web o móvil.
      2. Administración: mostrar el formulario, creación real de una plantilla y su identificador y estado en Meta.

      En Configuración básica de Meta revisá el ícono, categoría, política de privacidad, datos de contacto y las instrucciones de eliminación de datos. URLs públicas de esta app: Privacidad, Eliminación de datos y Condiciones.

      Esta consola no demuestra todavía el alta de otros negocios. La conexión multicliente mediante registro insertado es una etapa pendiente.
